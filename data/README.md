# Data Directory

This repository does not redistribute raw GWAS summary statistics or large reference resources.

Place files as follows:

```text
data/raw/          raw GWAS summary statistics downloaded from original sources
data/harmonized/   harmonized or LDSC-munged GWAS files used by scripts
data/reference/    LD reference panels, HapMap3 SNPs, LAVA resources, MAGMA resources, QTL resources
```

The definitive list of source datasets is provided in Supplementary Table 1 of the manuscript.
