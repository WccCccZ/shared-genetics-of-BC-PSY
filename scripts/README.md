# Script Notes

The scripts in this directory are executable templates for the manuscript analyses. Before running, update placeholder paths such as `/path/to/...` to match the local software, data, and reference-resource locations.

Recommended order:

```bash
bash scripts/run_ldsc_h2.sh
bash scripts/run_ldsc_rg.sh
bash scripts/MiXeR.sh
bash scripts/LAVA.sh
bash scripts/LCV.sh
bash scripts/run_lhcmr.sh
bash scripts/PLACO.sh
bash scripts/MAGMA.sh
bash scripts/SMR.sh
```

For detailed input and output descriptions, see `../docs/input_output.md`.
